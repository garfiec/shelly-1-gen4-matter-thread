# qrcodegen (C)

Nayuki's QR Code generator library, C version, unmodified: `qrcodegen.c` and `qrcodegen.h`.

- Source: https://www.nayuki.io/page/qr-code-generator-library, as vendored by connectedhomeip in `examples/common/QRCode/repo` (commit 8518684c0f33d004fa93971be2c6a8eca3167d1e), copied from the builder container.
- License: MIT, in each file's header.

The Wi-Fi mode page uses it to draw the setup code's QR (`qr_svg.c`).
